# Milo 最新情绪转盘与动态星空优化设计

状态：用户已确认执行
日期：2026-07-25
基线：`feature/glassy-space-orb` / `publish/main` @ `f51a606`

## 目标

在最新的 15 项圆形情绪环与 WebGL 深空背景上完成以下改进：

- 鼠标与手指在情绪球、圆环空白区滑动时都能直接切换情绪。
- 降低滑动切档距离，让拖动反馈即时可见，同时避免轻触误切。
- 增强球体位移、缩放、亮度与刻度环响应，保持“明显但克制”。
- 放大背景星点并增强指针/触摸视差。
- 从 WebGL 背景及其 CSS 降级层中彻底移除漩涡、旋臂和黑洞核心。
- 保留最新分支的 15 项圆形情绪顺序、点击展开、直接点击情绪、键盘操作和 `Milo-米洛` 品牌改动。

## 当前问题根因

1. `useMoodSwipe` 拒绝从按钮启动拖动，而可见情绪球上覆盖着 `.mood-orbit-toggle` 按钮，因此用户在最自然的球体区域滑动时不会触发手势。
2. `ECHO_MOOD_STEP_PX` 当前为 104px，移动端一次普通短滑很难跨过一个完整情绪档位。
3. 手势仅接受明显横向轨迹；竖向或斜向拖动会保持原情绪。
4. 视觉位移与手势阈值共用同一常量。直接缩短阈值会让球体位移更小，因此两者必须解耦。
5. `blackHoleGalaxyShader` 使用六层极小星点，并在顶部绘制 `tinyVortex`、`spiralDust`、`echoStream` 与中心暗核。

## 交互设计

- `.mood-orbit-toggle` 标记为允许拖动的交互表面；情绪文字和刻度按钮继续优先处理点击，不启动拖动。
- 手势移动超过 6px 后锁定横轴或纵轴，整次手势不切换主轴。
- 左滑或上滑前进一个情绪，右滑或下滑回到前一个情绪。
- 每累计 28px 移动一个连续情绪位置；松手后沿锁定轴计算速度并吸附到最近档位。
- 15 项情绪继续形成闭合圆环，保留最新版本的循环语义与点击最短路径。
- 每次跨越情绪索引继续触发轻震；不支持振动的设备静默跳过。

## 视觉设计

- 输入阈值与视觉轨道分离：视觉球体在半档内最多横移约 58px、下沉约 5px、缩小约 7%。
- 情绪索引变化时，新球体执行 360ms 的缩放与亮度脉冲；拖动中的刻度环同步提亮并轻微放大。
- WebGL 星点统一引入 `1.65` 尺寸增益，主星额外增加低强度柔光。
- 指针排斥位移从 `0.035` 提升到 `0.055`，并在 `pointerup` / `pointercancel` 后平滑归零，手指拖动不留下永久凹陷。
- 删除着色器中的全部漩涡函数和主函数叠加；降级 CSS 只保留多尺度星点。
- `prefers-reduced-motion` 下取消球体脉冲与刻度环缩放，但保留直接切档和静态视觉差异。

## 组件边界

- `moodSwipeModel.ts`：手势轴选择、位移映射、视觉轨道参数和现有圆环数学。
- `useMoodSwipe.ts`：Pointer Events 生命周期、轴锁定、速度采样与吸附。
- `MoodOrbitCarousel.tsx`：声明可拖动球体表面，消费更明显的轨道姿态。
- `index.css`：球体切档脉冲、拖动中刻度反馈、无动效降级和无漩涡 CSS fallback。
- `blackHoleGalaxyShader.ts`：多尺度星点、柔光、视差与无漩涡输出。
- `blackHoleGalaxyRenderer.ts`：指针结束时归零交互强度。
