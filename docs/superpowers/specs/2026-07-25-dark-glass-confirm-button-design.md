# 暗色真毛玻璃确认按钮设计规格

日期：2026-07-25
基线：`feature/glassy-space-orb` / `publish/main` @ `5e266a8`

## 目标

将 Echo Void 首屏的“就是这种感觉”按钮，从偏灰、偏实心的半透明质感，改成用户参考图红框中上方大号胶囊所呈现的暗色真毛玻璃。按钮仍然清晰可用，但能真正读到后方星空的模糊、折射和层次。

## 已确认的视觉方向

- 使用深色、高透明度的单色玻璃底，取代当前偏实心的灰色双层线性渐变。
- 星空需要透过按钮可见，同时被更强的模糊、饱和度和轻微明度处理融成一块深色玻璃。
- 边缘使用 1px 冷银灰线；上沿和左上侧更亮，下沿更暗，形成玻璃厚度。
- 内部加入克制的左上镜面亮斑、内侧折射线与一道非常柔和的斜向扫光，不覆盖文字。
- 阴影同时包含内高光、内暗边和低强度冷色外阴影，使按钮与黑色星空分离，但不变成发光按钮。
- 不使用参考图中的绿色/青色强彩边，不使用底部凸起的液态圆球，不新增装饰图片。

## 交互状态

- 默认态保持当前按钮尺寸、文字、居中布局和点击区域，不改业务逻辑。
- Hover 时只轻微提高边缘亮度、折射亮斑和外阴影，不改变整体色相。
- Active 时保留短促的下压缩放，增强内折射和模糊，让触感比默认态更明显。
- Focus-visible 保留可辨识的冷白焦点轮廓。
- 在 `prefers-reduced-motion: reduce` 下关闭扫光动画与伪元素过渡，但保留静态玻璃层次。

## 实现边界

- 仅修改 `src/index.css` 中 Echo Void 专用的 `.echo-confirm` 及相关伪元素/状态选择器。
- 可使用 `::before` 与 `::after` 分离“边缘折射”和“局部镜面亮斑”；伪元素必须不接收指针事件，不影响文字对比度。
- 不修改 React 结构、情绪转盘、WebGL 星空、其他页面的 `.btn-primary` 或数据流。
- 不增加新依赖或静态资产。

## 验收与验证

- 样式合约测试必须证明：暗色高透明背景、更强的 `backdrop-filter` 、冷银边缘、内外阴影、双伪元素、下压反馈和 reduced-motion 降级都存在。
- 已跟踪的全量测试、生产构建、Lint 和 `git diff --check` 通过。
- 在移动端和桌面端真实浏览器中确认：按钮后方星空可见但被显著模糊，边缘像玻璃而不是普通描边，文字清晰，且页面无横向溢出。
