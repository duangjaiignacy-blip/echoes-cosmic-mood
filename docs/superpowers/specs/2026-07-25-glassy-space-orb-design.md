# Echoes 宇宙玻璃情绪球设计规格

状态：已获用户确认
日期：2026-07-25

## 1. 背景

Echoes 首页的红框区域当前由 CSS 渐变绘制情绪球，外层是可拖动的环形拨盘。用户希望将球体视觉升级为 Recent Design 上「Glassy Space Sphere」的动态宇宙玻璃效果，同时保留现有拨盘旋转、情绪档位、颜色切换和脉冲反馈。

参考素材经核对为 540×540、8.5 秒、60fps 的循环动画：透明玻璃球壳内包含深紫色星云、多尺度星点、局部强光与边缘彩色棱镜折射。实现不直接使用或分发参考站的视频文件。

## 2. 目标

- 只替换红框中的球体渲染层，不改变首页导航、文案、拨盘、指示点、按钮和业务流程。
- 使球体具备参考效果的视觉结构：宇宙内核、玻璃球壳、彩色色散、镜面高光、发光星点与缓慢漂移。
- 保留情绪交互：拨盘角度控制宇宙内核旋转，连续情绪值控制颜色，跨越档位时继续触发脉冲。
- 在主流桌面和移动浏览器上保持清晰、流畅，并具有可用的降级表现。

## 3. 非目标

- 不复制 Recent Design 页面的导航、排版或其他内容。
- 不替换现有的 `useRotary` 手势模型。
- 不引入 Three.js 或视频播放依赖。
- 不在本次改造中调整词环步骤、其他页面或全局背景。

## 4. 技术方案

### 4.1 组件边界

`MoodOrb` 保留现有公共属性：

- `valence`：连续值 `-3..3`，输入情绪配色。
- `size`：球体 CSS 尺寸。
- `spin`：拨盘角度派生的内核旋转量。
- `pulse`：档位变化的短促缩放反馈。

组件内部新增一个透明 Canvas 渲染层。React 只负责创建、更新和销毁渲染器；WebGL 程序负责每帧绘制。现有 CSS 球体作为独立降级层保留，不与 WebGL 同时可见。

### 4.2 WebGL 渲染

使用原生 WebGL 和一个全屏四边形，由片元着色器在二维画布中解析构造球面：

1. 根据归一化坐标求出球面深度和法线，球外像素保持透明。
2. 将时间和 `spin` 合成旋转矩阵，用旋转后法线采样程序化宇宙内核。
3. 用多频噪声、局部亮核与暗区形成紫色星云；用稳定哈希网格产生大小和亮度不同的星点。
4. 使用 Fresnel 项构成透明球壳边缘，将 RGB 通道按轻微不同偏移采样，形成参考效果中的红、绿、蓝棱镜色散。
5. 叠加左上镜面高光、环境弧光、底部暗部和微弱外光晕，形成玻璃厚度。

着色器接收的动态参数只包含时间、分辨率、情绪三色、旋转角和脉冲强度，避免 React 每帧重渲染。

### 4.3 交互与动效

- 静置时宇宙内核持续以低速漂移，不改变拨盘的业务角度。
- 拖动拨盘时，`spin` 立即叠加到内核旋转，使视觉反馈与手指运动一致。
- `valence` 在相邻档位间连续插值，星云、弧光和外光晕同步过渡，不出现突变。
- `pulse` 沿用现有 450ms 缩放反馈，并短暂增加星云亮度，不改变震动反馈。
- 系统开启 `prefers-reduced-motion: reduce` 时停止自动时间推进，但仍允许用户主动拖动和变色。

### 4.4 尺寸与性能

- Canvas 的 CSS 尺寸继承 `size`，绘图分辨率根据实际尺寸和 `devicePixelRatio` 更新。
- 渲染 DPR 上限为 2，防止高分屏过度填充率。
- 使用 `ResizeObserver` 只在尺寸变化时调整缓冲区。
- 不创建多个 Canvas，不为每个星点创建 DOM 节点，不在动画循环中产生 React state。

## 5. 故障与降级

以下任一情况出现时，组件切换至现有 CSS 晶体球：

- 浏览器无法创建 WebGL 上下文。
- 顶点或片元着色器编译、链接失败。
- 运行中发生 `webglcontextlost`。

降级是组件内部行为，不向用户弹出技术错误，不阻断拨盘或下一步操作。开发环境保留简短错误日志供定位。

## 6. 验证方案

实施采用测试先行：

1. 先为连续情绪配色、DPR 上限、旋转参数换算、减少动效和降级判定编写失败测试。
2. 完成最小实现后运行全部单元测试。
3. 运行 `npm run build` 和 `npm run lint`，确认 TypeScript、Vite 与静态检查通过。
4. 在真实 Chromium 中验证 Canvas 获得 WebGL 渲染状态，页面无新增 console error。
5. 通过 Playwright 拖动拨盘，确认指示点、情绪文案、球体颜色和内核角度同步变化。
6. 以 445×805 移动视口和小型桌面视口截图，对照参考关键帧检查球体比例、星云层次、玻璃边缘、棱镜色散与整体亮度。

## 7. 验收标准

- 红框内球体在静置时呈现明显的宇宙星云和自动漂移，而非纯色渐变球。
- 球体边缘可见透明厚度、镜面弧光与红绿蓝棱镜色散。
- 拨盘旋转时星云响应方向和速度连续，情绪档位、文案和原有振动反馈不退化。
- `-3..3` 全部情绪区间的颜色过渡无闪烁和硬切换。
- WebGL 失败时立即显示 CSS 降级球，主流程仍可完成。
- 移动视口无横向溢出，球体与外层拨盘保持居中和原有尺寸关系。
- 生产构建、静态检查和新增测试全部通过。
