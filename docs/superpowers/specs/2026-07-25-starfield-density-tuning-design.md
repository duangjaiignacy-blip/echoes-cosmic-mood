# Milo 星空密度微调设计

状态：用户已确认
日期：2026-07-25
基线：`feature/glassy-space-orb` / `publish/main` @ `40c4976`

## 目标

保留当前清晰的大星尺寸、六层深度运动和指针视差，只拉开星点之间的视觉距离，避免背景形成连续的白色噪点墙。

## 调整方案

- 微尘层出现频率从 `0.26` 降至 `0.16`，约减少 38%。
- 两层中景星出现频率分别从 `0.105`、`0.075` 降至 `0.079`、`0.056`，约减少 25%。
- 两层主星的出现频率、`1.65` 尺寸增益和柔光强度保持不变。
- 全局亮度、颜色、星点运动速度和指针排斥效果保持不变，确保结果是“更疏朗”而不是“更暗”。
- CSS 降级星空保持现状，本轮仅调整用户实际看到的 WebGL 背景。

## 验收

- 标题、球体和按钮附近能看到更多纯黑留白。
- 大星仍清晰可见，背景层次没有被削平。
- 不重新出现漩涡、流线或黑洞核心。
- 构建、静态检查和已跟踪测试通过。
- 在 445×805 移动视口截图确认整体密度明显下降但不空洞。
