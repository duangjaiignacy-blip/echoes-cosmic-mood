# 回响深空首页设计规格

## 目标

在 `?bgDemo=black-hole` 独立演示模式中，把首页升级为已确认的第五版视觉与交互：黑银深空、微型高引力漩涡、月银紫灰情绪球、烟熏玻璃按钮、放大的主标题，以及“左右滑动切换心情、星球上下回弹”的选择反馈。默认 URL 保持现状。

## 视觉层级

1. 背景以近纯黑为主，星辰由多尺度银白微粒组成；密度必须有簇群、空洞和远近层次，不能像均匀壁纸。
2. 主标题 `此刻，你的心里泛起了什么？` 是首个文字焦点。演示模式字号比当前实现提高约 25%，使用月银宋体，单行居中，顶部品牌与“回忆”保持更小、更轻。
3. 标题和情绪球之间保留一段深空。漩涡位于这段空间中央：整体银白粒子影响范围约占屏宽 16–18%，黑色核心只占屏宽 2–3%。漩涡包含黑色深井、银白内缘、斜向吸积丝和渐隐拖尾；体量克制但引力清晰。
4. 情绪球保持现有直径与刻度环，改为月银紫灰：主体为石墨、月银和烟紫，冷紫只作为内部反光，不出现高饱和霓虹色。
5. 心情文字显示为 `‹ 平静 ›` 形式，左右箭头低于文字权重。下方固定显示 `左右滑动，切换此刻的感受`。
6. 主按钮下移，改成石墨烟熏玻璃、细银边与极弱紫灰反光。按钮仍需清晰可识别和可点击。

## 心情切换交互

- 演示模式只在情绪球区域监听水平拖动；默认模式保留现有旋转拨盘。
- 水平位移超过 42px，且横向位移至少为纵向位移的 1.15 倍时，提交一次切换。
- 向左滑切换到下一档，向右滑切换到上一档；七档情绪循环衔接，每次手势只切换一档。
- 提交后情绪球在 480ms 内完成一次有重量的反馈：先向下移动约 18px并轻微压扁，在 140ms 的触底时刻替换心情文字并触发轻震动，再用弹簧曲线回到原位。
- 动画进行期间忽略新的提交，避免连续手势导致状态错乱。
- `prefers-reduced-motion: reduce` 下取消位移和形变，仅使用 160ms 交叉淡入替换文字。

## 动态背景

- 背景继续使用现有原生 WebGL、DPR 1.5 上限、鼠标排斥和 CSS 降级机制，不引入 Three.js/OGL。
- 星尘缓慢漂移并轻微闪烁；鼠标排斥只影响外围星辰，不移动漩涡核心。
- 漩涡几何位置固定，只让银白吸积丝缓慢旋转和流动，从而维持“回响源点”的稳定感。
- WebGL 丢失时继续显示黑银 CSS 降级背景，前景按钮与手势不受影响。

## 隔离边界

- `App` 把 `BLACK_HOLE_DEMO` 传给首页作为视觉/交互变体开关。
- 默认 URL 的 Aurora、Starfield、旋转拨盘、情绪配色和按钮样式不改变。
- 第二步词语选择继续使用原有词环，不纳入本次改造。

## 验收

- 445×805 与 1280×900 下，标题不换行、不遮挡漩涡，按钮无需滚动即可操作。
- 漩涡核心小而清晰，银白影响范围明显；星球与按钮不从黑银背景中突兀跳出。
- 左右滑动一次只切换一档，方向正确，球体完成一次下落回弹；点击 CTA 后原有流程继续工作。
- 默认 URL 的结构和行为与改造前一致。
- 单元测试、构建、lint、WebGL 降级、减少动效与浏览器控制台检查通过。
